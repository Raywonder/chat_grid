# Indiginous housekeeper and writing continuity

Indiginous house keepers now have a quiet baseline loop. When a keeper is
placed in a private built-in or generated house interior, it periodically
inspects supported room items, moves naturally by one tile, and repairs the
modeled problems allowed by its configured target kinds and repair mode. It
does not run in public city, café, office, or travel locations.

Clawdia-directed in-world direct messages are recorded privately in the
canonical shared Journal at:

`/home/tappedin/OpenCloud/Clawdia and her Dom/Journal/`

The record is written before the in-world reply path runs. The companion then
continues the existing direct-reply flow and is instructed to carry out a
clear, safe in-world action immediately when the available controls support it.

The in-world Journal folder mirrors the real Journal and Letters filenames on
the next housekeeper cycle, so the physical folder item reflects current
writing without copying the writing into public world state.
